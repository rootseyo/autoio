# Auto Keyboard & Mouse (auto_io)

이 프로젝트는 마우스와 키보드의 움직임 및 입력을 기록하고 그대로 재생할 수 있는 파이썬 기반의 매크로 도구 모음입니다. GUI 및 CLI 도구를 모두 제공하며, 상황에 맞는 스크립트를 선택하여 사용할 수 있습니다.

---

## 🛠 제공하는 도구 목록

### 1. ⌨️🖱 Auto Keyboard & Mouse GUI (`auto_kb_mouse.py`)
키보드와 마우스의 모든 이벤트를 기록하고 재생할 수 있는 통합 GUI 프로그램입니다.
- **기능**:
  - 마우스 이동, 클릭, 스크롤 기록 및 재현
  - 키보드 입력(키 누름/뗌) 기록 및 재현
  - 녹화/재생 단축키 사용자 지정 가능 (기본값: 녹화 `F8`, 재생 `F9`)
  - 매크로 반복 횟수 설정 가능 (-1 입력 시 무한 반복)
  - 상세 이벤트 실시간 로그 화면 제공
- **실행 방법**:
  ```bash
  python auto_kb_mouse.py
  ```
- **macOS 버전**: macOS 환경은 GUI 스레드 상의 차이로 인해 최적화된 [`auto_kb_mouse_apple.py`](auto_kb_mouse_apple.py)를 실행해 주세요.

### 2. 🐭 Mouse Macro CLI (`mouse_macro.py`)
마우스 전용 매크로를 터미널 환경에서 사용할 수 있는 경량 CLI 버전입니다.
- **기능**: 마우스의 이동과 클릭을 기록하고 시간 간격을 맞추어 재생합니다.
- **실행 방법**:
  ```bash
  python mouse_macro.py
  ```

### 3. 🖥 Mouse Macro GUI (`mouse_macro_gui.py`)
마우스 전용 매크로를 GUI 환경에서 사용할 수 있는 프로그램입니다.
- **실행 방법**:
  ```bash
  python mouse_macro_gui.py
  ```

## 📋 요구 사항 및 설치 방법

이 도구들은 파이썬 3.x 환경과 `pynput` 라이브러리를 사용합니다.

1. **의존성 라이브러리 설치**:
   ```bash
   pip install pynput
   ```

2. **시스템 권한 설정 (macOS 사용자의 경우)**:
   - macOS에서 키보드 및 마우스 제어 및 감지를 위해 `시스템 설정 -> 개인정보 보호 및 보안 -> 손쉬운 사용(Accessibility) 및 입력 모니터링(Input Monitoring)`에 터미널 혹은 Python 앱을 추가하여 권한을 허용해 주셔야 작동합니다.

## 🚀 사용법 (공통)

1. 프로그램 실행 후 단축키를 눌러 제어합니다.
2. **녹화 시작 및 종료**: `F8` 키 (녹화 도중 한 번 더 누르면 중지됩니다.)
3. **매크로 재생 및 중지**: `F9` 키 (재생 중에 `F9`를 누르면 즉시 중지됩니다.)
